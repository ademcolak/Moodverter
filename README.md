# Moodverter

Moodverter, YouTube'dan şarkı bulup eklemeyi ve rahat şekilde çalmayı hedefleyen basit bir masaüstü widget'ıdır. Proje şu an bilinçli olarak dar kapsamda: sadece YouTube arama/ekleme/çalma akışı.

## Özellikler

- YouTube linki yapıştırarak hızlı şarkı ekleme
- YouTube arama sonuçlarından şarkı seçip çalma
- Yerel kütüphaneye ekleme/silme
- Temel oynatma kontrolleri: play/pause/next/previous/seek
- Tauri tabanlı macOS/Windows masaüstü uygulaması

## Hızlı Başlangıç

```bash
pnpm install
pnpm tauri dev
```

Notlar:
- Tauri geliştirme için Rust kurulu olmalıdır.

## Komutlar

```bash
pnpm dev
pnpm tauri dev
pnpm lint
pnpm build
```
